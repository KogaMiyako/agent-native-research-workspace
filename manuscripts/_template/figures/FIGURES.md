# 图索引

本文件是本稿件图资产、论文图号、候选版本和当前采用图的索引。管理流程见 [manuscripts/README.md](../../README.md)，稿件入口见 [稿件 README](../README.md)。

## 当前采用图

未采用的候选不填入此表。资产 ID 与论文图号独立，论文重排时仅更新图号和 label 的实际映射。

| 资产 ID | 主题 | 论文图号 / label | 采用版本 | 稳定文件路径 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

稳定文件路径相对本稿件目录填写，例如 `figures/F01-<topic>/figure.pdf`。正文引用此入口，不直接引用候选版本。

## 候选与历史版本

同一资产的版本取已有最大值加一，已有目录不覆盖。采用后候选原件仍保留；补存历史采用图时注明归档性质和已知来源，未知信息如实保留。

| 资产 ID | 版本 | 文件路径 | 修改说明 / 归档说明 | 生成入口与代码版本 | 数据或参考来源 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

候选路径相对本稿件目录填写，例如 `figures/candidates/F01-<topic>/v001/figure.pdf`。预览统一使用同目录下的 `preview.png`；按需保存 SVG、位图或可编辑文件，注明实际主文件格式。

## 来源记录要求

* 生成入口写明 `repos/<repo>/` 内的脚本、实际命令和代码提交或必要指纹；手工绘制则注明编辑工具和可编辑源文件路径。
* 实验图注明实际 Experiment、Run 及输入文件；多个来源分别列明。数值变换、筛选或归一化应能回到相应分析记录或生成代码。
* 方法示意图注明方法文档、设计依据或参考素材；不要求为概念图创建 Run。
* 借鉴外部论文图的布局或表达方式时，按 [参考资料规范](../../../references/README.md) 在本表来源字段链接到对应 `references/papers/<paper-id>/PAPER.md` 的图记录，保留原图号和 PDF 页码。摘图留在 references，自己的候选图使用自己的方法内容或实验数据。
* 需要固定关键输入或采用文件时可记录 SHA256；不以无法核实的提交或来源填充记录。
* 同版本的多个导出格式和预览应对应相同内容。改变内容、样式或案例时建立新版本。

仅画候选时更新候选表。明确采用后，先确保旧图可以恢复，再更新稳定文件和采用表；需要正文引用或布局变化时按稿件构建方式检查。
