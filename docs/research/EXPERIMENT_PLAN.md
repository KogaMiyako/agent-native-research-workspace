# 正式实验与证据计划

本文档用于在完整方法候选形成后，规划论文所需的正式实验证据。

正式实验应覆盖完整方法的整体效果、各创新点的贡献、方法的稳定性和必要的机制解释。创新点的初步验证记录在 `METHOD.md`；本文件通过 Experiment 编号与其衔接。

实验结果产生后，应逐步整理到本文档中。详细执行记录仍保留在本文档之外。
