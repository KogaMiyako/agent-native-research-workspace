# 参考资料

此目录保存外部论文及阅读成果。同一篇论文的绘图参考和写作结构分析共用一份原文与笔记；作者自己的稿件和图仍归 `manuscripts/`，本项目的研究结论仍归 `docs/research/`。

论文入口：[总索引](papers/INDEX.md)、[单篇笔记模板](_template/PAPER.md)。其他外部材料按项目需要组织，不必放入论文索引。

## 目录

```text
references/
├── README.md
├── _template/
│   ├── PAPER.md
│   └── figures/
└── papers/
    ├── INDEX.md
    └── <paper-id>/
        ├── paper.pdf
        ├── PAPER.md
        └── figures/
            └── fig02-p05.png
```

`paper-id` 使用简短稳定的英文标识，例如 `<year>-<author>-<short-title>`。标识冲突时补充可区分的短后缀；不因下载文件名变化而建立重复条目。

* `paper.pdf`：实际获得的正文 PDF，保留原始内容。
* `PAPER.md`：身份和来源、选图说明、结构分析及对自己稿件的启发。
* `figures/`：已选择、检查并在笔记中登记的参考图。
* `papers/INDEX.md`：检索入口与整理进度，不复制各篇完整分析。

模板只提供笔记和图目录，不放空 PDF 或示例论文。

## 收集与查重

1. 在总索引中按题名、作者和 DOI/arXiv 等标识检查是否已有。再次用于另一目的时，补充原条目。
2. 新论文将 `_template/` 复制为 `papers/<paper-id>/`，把实际获得的正文保存为 `paper.pdf`。
3. 在 `PAPER.md` 填写题名、作者、年份、来源链接或标识、实际文件版本与获取来源。出版或投稿状态不确定时写“未确认”。
4. 在总索引增加笔记链接和关注点，分别记录图参考与结构分析进度。

两个用途独立维护，允许只摘图、只做结构分析或两者兼用。仅收到文件时记为尚未整理，不把收集等同于完成阅读。按需记录正在整理的范围，不要求每篇论文都填写全部分析。

正文和补充材料分开标识。若使用补充 PDF，可保存为 `supplement.pdf` 或 `supplement-<name>.pdf`，在笔记中分别记录实际版本与来源。引用页码时注明具体文件，不能把不同版本的页码混用。

## 摘图与绘图参考

围绕实际目的选图，例如方法总览、问题动机、案例对比、多面板结果、消融、参数曲线或机制示意，不默认导出全文所有图。

1. 阅读原页并确认原图号、子图范围和表达目的。
2. 用现有 PDF 工具从页面渲染结果裁切完整图区域。复杂图的箭头、文字和坐标轴可能是独立元素，仅提取内嵌图片可能不完整。
3. 检查清晰度、裁切边界、图例和子图；将选中结果保存到 `figures/`。
4. 更新笔记的图参考记录，并同步总索引中的关注点和进度。

文件名包含原图号和 PDF 页码，例如 `fig02-p05.png`；必要时加子图标识，如 `fig02b-p05.png`。补充图按其实际图号命名。PDF 页码从 1 开始，与文章印刷页码分开记录。

每张图记录原图号、PDF 页码、本地图链接、表达任务、可借鉴的具体设计，以及适用于自己哪类图、需要什么输入。若记录裁切区域，注明工具、坐标单位、原点和渲染缩放，便于重新定位。

图记录应能回答“为什么参考它”，例如面板安排、阅读顺序、颜色语义或局部放大方式，而不只写“好看”。原始参考摘图保持原意；自己的设计变体进入 `manuscripts/` 的候选流程。

## 写作结构分析

按需要完成三层分析，在笔记中保留原文位置：

| 层次 | 记录重点 |
| --- | --- |
| 全文章节 | 实际章节/小节、页码、各自任务、前后衔接及可借鉴之处 |
| 重点段落 | 选择需要学习的部分，说明每段的论证任务、具体论据和过渡关系 |
| 对自己稿件的启发 | 可借鉴的组织方式、拟用于自己哪一部分、所需证据或尚缺材料 |

引言可关注问题如何逐步具体化、缺口如何建立、解决思路怎样引出；相关工作可关注分类维度和比较关系；方法可关注定义、模块、公式与图的先后；实验可关注各组实验回答的问题与表图如何支撑结论。

保留原论文的实际结构，不强制套用固定段落顺序。区分原文事实与自己的解释，使用页码、章节和段落起始位置定位；写简洁的分析，不以复制长段原文替代结构理解。

## 后续使用

绘图时，从总索引和图参考记录中选择适合的设计，结合自己的方法或实验数据生成稿件候选图。在稿件 `FIGURES.md` 的来源字段链接到对应 `PAPER.md` 的图记录，保留原图号与页码；参考摘图不直接变成当前采用图。

拟定写作提纲时，结合多篇结构分析与本项目实际方法、证据选择组织方式。结构笔记是阅读理解和候选方案，不自动成为本项目结论，也不表示已授权修改论文正文。形成稳定研究认识时再按根规则提炼到现有规范研究文档。

## 保存与 Git

默认跟踪本目录说明、总索引、笔记模板、逐篇笔记和精选参考图。原文 `papers/<paper-id>/paper.pdf` 与 `supplement*.pdf` 默认本地保存并被 Git 忽略；需要随仓库保存原文时可按项目调整规则。

笔记应记录可恢复的来源、实际文件版本和获取日期；必要时记录 SHA256，避免恢复为不同版本。仅有本地提供文件且没有可下载入口时，注明本地保管或备份来源，不声称能从链接恢复。

全量页面渲染、OCR 和未选中的提取结果放到根 `tmp/`。不要忽略整个 `papers/`，也不要全局忽略 PDF，否则会隐藏笔记、参考图或作者自己的图资产。新增忽略规则不会自动取消已有文件的跟踪。
